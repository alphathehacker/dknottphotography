# DKNOTT Photography — Website (Flask version)

A multi-page wedding photography brand website built with Python Flask and Jinja templates.

**Pages:** Home, Our Story, Wedding Films, Real Weddings, Client Guide, Contact.

> **Context:** this repository is the earlier Flask version of the DKNOTT Photography site. The live client website was later rebuilt with a different stack (React + Sanity) under the client's own account; this repo is kept as the original build.

## Tech stack

- Python (Flask) + Jinja2 templates
- Static assets in `public/`
- Deployed to Vercel (`vercel.json`)

## Run locally

```bash
pip install -r requirements.txt
python app.py
```

On Windows, `run_server.bat` is a convenience script that does the same thing.
